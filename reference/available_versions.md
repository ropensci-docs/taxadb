# Versions of the taxadb data available

Versions of the taxadb data available

## Usage

``` r
available_versions(db = td_connect())
```

## Arguments

- db:

  a connection from
  [`td_connect()`](https://docs.ropensci.org/taxadb/reference/td_connect.md)

## Value

a character vector of available snapshot versions

## Examples

``` r
if (FALSE) { # \dontrun{
available_versions()
} # }
```
